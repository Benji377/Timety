## Get help

Didn't find what you were looking for?

- **Ask the community** in [GitHub Discussions](https://github.com/Benji377/Timety/discussions).
- **Report a bug or suggest a feature** with the [feedback form](https://tally.so/r/ODbEoA). No account needed.
- **Write an email** to [apptimety@gmail.com](mailto:apptimety@gmail.com).

Want to improve a guide? They're plain Markdown files in the [`docs` folder](https://github.com/Benji377/Timety/tree/main/docs). See [CONTRIBUTING](../CONTRIBUTING.md#user-guides) for how they're written.
